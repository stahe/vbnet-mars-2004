# Introduction au langage VB.NET par l'exemple

👉 Cours associé : [Introduction au langage VB.NET par l'exemple](https://stahe.github.io/vbnet-mars-2004/)

## Contenu

Ce support couvre les principaux thèmes suivants :

- Bases du langage VB.NET
- Programmation orientée objet
- Interfaces graphiques
- Gestion d'événements
- Accès aux bases de données
- Programmation TCP/IP
- Services web

## Objectif

Fournir une introduction progressive à VB.NET au travers d’exemples pratiques, des fondamentaux jusqu’à des sujets applicatifs (GUI, réseau, données, web services).
